## 介绍：

本地电脑上的MT5直连中国期货交易所行情和交易，实现交易国内商品期货、股指期货、原油期货，支持EA量化开发与策略回测

- **合法合规：** 根据国家期货金融监管要求，您需在期货公司完成“穿透式监管”申报及开通，方可使用本期货软件
- **资金安全：** 继续使用您现有的期货账户和银行账户，资金不经过第三方托管，不需要重新开户
- **支持全部期货公司：** 所有支持CTP接口的期货公司均可接入使用，不限制您到指定的期货公司开户
- **CTP直连低延迟超稳定：** 传统交易软件（转发架构）期货交易所行情 → 交易软件商转发服务器 → 您的电脑，本软件期货交易所行情 → 直接到达您的电脑MT5，数据零中转，极速直达，交易指令直通交易所
- **实时行情：** 接入国内期货市场全品种实时行情

## 行情功能：

- **实时行情：** 接入国内期货市场全品种实时行情
- **历史行情：** 提供全部期货合约自上市以来完整历史数据，包括商品期货、股指期货、原油期货、主力连续合约
- **主力连续合约：** 提供2005年以来主要期货品种主力连续合约历史数据，适用于量化研究和策略回测
- **全品种覆盖：** 覆盖上期所、大商所、郑商所、中金所、能源中心、广期所所有期货品种

## 交易功能：

- **使用MQL5开发期货EA：** 提供完整MQL CTP接口，轻松开发期货自动交易策略
- **策略保密：** EA运行于本地电脑，策略源码不会上传第三方平台
- **支持多策略：** 多个EA同时运行，互不影响
- **支持回测：** 基于全市场品种自2005年以来完整历史行情数据进行高质量回测

### 📥 如何安装众胜MT5期货

> **安装说明：** 众胜MT5期货可以安装在任意一个平台的MT5上，但是必须开通一个该平台的账号，至于该账号是模拟的还是实盘的无所谓。除了该账号以外，本软件和该MT5平台没有关系。

#### 步骤一：下载并安装MT5平台

#### 步骤二：开通MT5平台账号

#### 步骤三：下载众胜MT5期货安装包

#### 步骤四：安装软件

打开MT5的数据文件夹并复制该目录路径。

![](https://www.wewin28.com/image/mt5-china-futures-data-folder.png)
![](https://www.wewin28.com/image/mt5-china-futures-data-folder-path.png)

把复制的MT5数据文件夹目录路径粘贴到安装界面。

![](https://www.wewin28.com/image/mt5-china-futures-install-folder.png)

安装成功完成。

#### 步骤五：配置MT5允许DLL导入

然后重启MT5。

![](https://www.wewin28.com/image/mt5-china-futures-tool-option.png)

勾选“允许DLL导入”。

![](https://www.wewin28.com/image/mt5-china-futures-tool-option-ea.png)

#### 步骤六：启动众胜MT5期货服务

点击服务，逐一启动各个众胜MT5期货服务。

> **注意：** 每个服务只能启动一次，不能启动多次，否则会影响软件使用。

#### 步骤七：完成安装

再次重启MT5，看到每个服务都成功启动（显示灰色三角形）

![](https://www.wewin28.com/image/mt5-china-futures-service-ok.png)


> **安装完成：** 至此，众胜MT5期货已成功安装。现在可以开始配置期货账号，进行实盘或模拟交易了。
